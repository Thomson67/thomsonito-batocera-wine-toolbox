# Ultimate Wine Toolbox v0.5.1

## Français

### Starter Pack

- Ajout de **GE-Proton10-25 classique**. La version **GE-Proton10-25-UMU** reste disponible.
- Ajout de **dwproton-11.0-14-UMU** en remplacement du DW-Proton classique dans le pack.
- Le pack contient désormais **13 runners classiques et 4 runners UMU**.
- Ajout du menu **Consulter les runners du Starter Pack** : liste défilante des runners classiques et UMU, avec l'état **Installé / Manquant**.
- Les installations portant encore un ancien nom de dossier sont reconnues.

### Installation UMU

- Prise en charge de l'installation automatique de DW-Proton depuis le Starter Pack avec les versions actuelles d'UMU Runner Toolbox.
- Réutilisation des contrôles d'intégrité et de la préparation du Steam Runtime requis.
- Un échec d'installation DW est signalé lorsque le runner final n'a pas de manifeste valide.

Les runners déjà installés sont conservés. Pour ajouter les nouveaux composants, ouvrir **Starter Pack → Choisir les runners à installer**, ou installer tout le pack manquant.

Les workflows de création et de mise à jour des wsquashfs restent en **bêta**.

### Installation / mise à jour

```bash
curl -fsSL https://raw.githubusercontent.com/Thomson67/ultimate-wine-toolbox/main/install.sh | bash
```

## English

### Starter Pack

- Added **classic GE-Proton10-25**. **GE-Proton10-25-UMU** remains available.
- Added **dwproton-11.0-14-UMU**, replacing classic DW-Proton in the pack.
- The pack now contains **13 classic runners and 4 UMU runners**.
- Added **View Starter Pack runners**: a scrollable list of classic and UMU runners with their **Installed / Missing** status.
- Existing installations using legacy folder names are recognized.

### UMU installation

- Added automatic DW-Proton installation from the Starter Pack using current UMU Runner Toolbox versions.
- Reuses runner integrity checks and preparation of the required Steam Runtime.
- Reports failed DW installation when the final runner has no valid manifest.

Installed runners are preserved. To add the new components, open **Starter Pack → Choose runners to install**, or install all missing pack components.

The wsquashfs creation and update workflows remain in **beta**.

### Install / update

```bash
curl -fsSL https://raw.githubusercontent.com/Thomson67/ultimate-wine-toolbox/main/install.sh | bash
```
