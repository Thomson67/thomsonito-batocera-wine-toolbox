# Ultimate Wine Toolbox v0.3.0

## Français

### Mettre à jour un jeu dans un WSquashFS — bêta

Nouvelle option après « Créer un WSquashFS ». Elle extrait le préfixe, remplace le dossier du jeu par déplacement de la nouvelle version, puis reprend le workflow de test avant recompression.

- Priorité aux archives ayant un dossier de mise à jour correspondant, avec prise en compte des balises de runner/manette dans les noms.
- Conservation du nom du dossier du jeu, des scripts de lancement, des liens de sauvegarde et des réglages EmulationStation.
- Exécutable et règles de sauvegarde existants proposés par défaut, avec possibilité de changer.
- Liens vers `/userdata/saves/windows` conservés avec leur cible d’origine, sans fenêtre spéciale.
- Préfixe de test portant le nom du jeu en `.wine` et lien `root` vers `steamuser` préparé automatiquement.
- Validation du lancement, options du jeu et HIDRAW, puis contrôle complet de la nouvelle archive.
- Remplacement direct ou sauvegarde de l’ancienne archive avant remplacement.
- Annulation possible si le préfixe de travail a disparu. Suppression des sauvegardes temporaires après réussite, conservation en cas d’échec ou d’opération en attente.

**La fonction de mise à jour reste en bêta**, en attendant sa validation sur davantage de jeux. Le dossier de nouvelle version est déplacé dans le préfixe de test ; il ne reste pas à son emplacement initial. Les liens vers la racine partagée utilisent directement les sauvegardes existantes pendant le test.

### Autre correction

Les éventuels `autorun.cmd` ne sont plus proposés comme exécutables du jeu lors de la création.

## English

### Update a game inside a WSquashFS — beta

New option immediately after Create. Extract the existing prefix, move the updated game directory into place, test launch and saves, then recompress.

- Prioritize matching update folders, ignoring trailing runner/controller tags when matching names.
- Preserve the game directory name, launch scripts, save links and EmulationStation settings.
- Default to the existing executable and save rules, with alternatives available.
- Keep links to `/userdata/saves/windows` unchanged without a special prompt.
- Use the game’s `.wine` name for testing and automatically prepare the `root` alias to `steamuser`.
- Review launch, game options and HIDRAW; fully check the new archive before replacement.
- Replace directly or back up the previous archive first.
- Allow cancellation when the working prefix is missing. Remove temporary test saves after success; retain them on failure or while pending.

**The update feature remains in beta** pending tests with more games. The updated source directory is moved into the test prefix and no longer remains at its initial location. Shared-root save links use existing saves directly during testing.

### Other fix

Exclude `autorun.cmd` files from game executable selection during creation.
