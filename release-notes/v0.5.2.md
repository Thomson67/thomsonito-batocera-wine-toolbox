# Ultimate Wine Toolbox v0.5.2

## Français

### Création de WSquashFS — bêta

- Ajout de l'option **Installer des Winetricks supplémentaires** après un échec de lancement ou lorsque le jeu est déclaré non fonctionnel : liste de composants courants et saisie manuelle.
- L'installation utilise le runner choisi pour le jeu, indique les erreurs dans le journal et propose de refaire le test. Le préfixe est conservé en cas d'échec.
- Ajout de **Fichiers de sauvegarde dans le dossier du jeu** pour les sauvegardes individuelles nécessitant `SAVEFILES`.
- Comparaison des fichiers avant/après le test, affichage des fichiers créés ou modifiés avec leur taille, et sélection manuelle des fichiers existants.
- Les fichiers sont décochés par défaut : les réglages ou logs modifiés ne sont pas automatiquement considérés comme des sauvegardes.
- Configuration de `SAVEDIR` et `SAVEFILES` à partir des fichiers choisis dans un même dossier.
- Les fichiers sélectionnés sont copiés vers `/userdata/saves/windows/<jeu>`, puis retirés du préfixe avant compression. Batocera recrée leurs liens au lancement. L'exécutable et les autres fichiers du dossier du jeu sont conservés.
- Les modes sauvegarde d'un dossier complet et sauvegarde du registre restent disponibles.

Pour aider la détection, créer une véritable sauvegarde pendant le test du jeu. Une sélection `SAVEFILES` concerne un seul dossier ; les noms contenant un point-virgule ne sont pas pris en charge.

Les workflows de création et de mise à jour des WSquashFS restent en **bêta**.

### Installation / mise à jour

```bash
curl -fsSL https://raw.githubusercontent.com/Thomson67/ultimate-wine-toolbox/main/install.sh | bash
```

## English

### WSquashFS creation — beta

- Added **Install additional Winetricks** after a failed launch or when the game is reported as not working: common components and manual verb entry.
- Installation uses the game's selected runner, logs errors and offers another test. The prefix is preserved on failure.
- Added **Save files in the game directory** for individual saves requiring `SAVEFILES`.
- Compares files before/after the test, lists created or modified files with their sizes, and provides manual selection of existing files.
- Files are unchecked by default: modified settings or logs are not automatically treated as saves.
- Configures `SAVEDIR` and `SAVEFILES` from the selected files in one folder.
- Selected files are copied to `/userdata/saves/windows/<game>`, then removed from the prefix before compression. Batocera recreates their links at launch. The executable and other game files are preserved.
- Whole-directory and registry save modes remain available.

Create an actual save during the game test to help detection. One `SAVEFILES` selection uses a single folder; filenames containing a semicolon are unsupported.

The WSquashFS creation and update workflows remain in **beta**.

### Install / update

```bash
curl -fsSL https://raw.githubusercontent.com/Thomson67/ultimate-wine-toolbox/main/install.sh | bash
```
