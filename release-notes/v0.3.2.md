# Ultimate Wine Toolbox v0.3.2

## Français
### Correction du scrap Batocera
- Les médias sont maintenant installés dans les sous-dossiers standard `media/images`, `media/box2d`, `media/fanarts`, `media/marquee` et `media/thumbnails`.
- Les chemins relatifs correspondants sont ajoutés à la fiche du jeu dans `gamelist.xml`.
- Les champs média vides ou encore renseignés avec les anciens chemins sont corrigés; les valeurs personnalisées existantes restent préservées.
- L’intégration corrige aussi les fiches déjà créées lors d’une mise à jour.

## English
### Batocera scraper fix
- Media is now installed under Batocera's standard `media/images`, `media/box2d`, `media/fanarts`, `media/marquee` and `media/thumbnails` folders.
- Matching relative paths are written to the game's `gamelist.xml` entry.
- Empty media fields and fields still using the previous generated paths are fixed, while existing custom values are preserved.
- Updates also repair entries created by earlier versions.
